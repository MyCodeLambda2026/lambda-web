Lambda Custom Language — Full Official Syntax Manual (English)
Matches current compiler: || operator, >> comment, not‑in optimization.
NOTE: Classes / classes keyword removed in current version.

==================== Lambda Language Syntax Guide ====================

1. Basic Rules
All code blocks must use curly braces { }.
{ and } must be paired. Unbalanced braces → error[11].
Native Python keywords (like if, for, try) are forbidden.
Comments start with >> (full‑line or inline).
Semicolon ; is optional but recommended for assignment.

2. Variable Assignment
Syntax:
variable setitem value;

Example:
a setitem 10;
name setitem "Lambda";

3. Output (Print)
Syntax:
printe content

Example:
printe 100
printe "Hello World"
printe a

4. Conditionals
If
If condition do{
    code
}

Elif
Elif condition do{
    code
}

Else
Else do{
    code
}

Full Example:
If a <> 5 do{
    printe "a equal to 5"
}
Elif a !- 3 do{
    printe "a not equal to 3"
}
Else do{
    printe "other branch"
}

5. Loops
While Loop
While condition do{
    code
}

For Loop
var For into iterable do{
    code
}

Example:
i For into reg(1,10) do{
    printe i
}

6. Error Handling (Try / Except)
Try{
    risky code
}
Except{
    handle error
}

Example:
Try{
    unknown_var setitem 10;
}
Except{
    printe "Error caught"
}

7. Operators
----------------------------------------------------------------------
Your Syntax     Python Equivalent       Meaning
----------------------------------------------------------------------
a <> b          a == b                  equal
a !- b          a != b                  not equal
a -> b          a in b                  membership test
a || b          a or b                  logical OR
a & b           a and b                 logical AND
<!> a           not a                   logical NOT (prefix only)

Note: To get "a not in b", write:  <!> a -> b
Compiler will optimize internally to Python "a not in b".

8. Functions
Define Function (no parameters)
funcname perform{
    code
}

Define Function (with parameter)
funcname perform param{
    code
}

Example:
test perform{
    printe "Hello from function"
}
